# signal-peptide-features

[English](README.md) · [特徴量の全定義と出典](docs/methods.md)

**一つのシグナルペプチドを、前駆体と切断点の文脈から調べる。**

v0.3では、ブラウザで使えるローカルGUIを追加しました。配列の残基を選ぶと、
物性グラフと切断点の拡大表示が連動します。N/H/C領域の推定、
生理学的な過程と物性のマトリクス、指標ごとの出所表示にも対応しています。
二配列以上の比較はAdvancedにまとめました。変異の解析は従来のCLIで利用できます。

```bash
# From the repository directory
pip install -e '.[gui]'
sp-features gui
# ブラウザで http://127.0.0.1:8765 を開く
```

配列は直接貼り付けるか、FASTAファイルを読み込みます。
切断位置やSPの種類が未入力なら、設定済みのTSignalで補います。
TSignalが未設定の場合は、不明のまま解析します。
JSONで解析と表示状態を保存・再読込でき、CSV・HTML・SVGも出力できます。
PDFはブラウザの印刷機能で保存します。

汎用のペプチド物性計算を行う[peptides.py](https://peptides.readthedocs.io/)に対し、
本ツールはシグナルペプチド領域と、切断点の前後（成熟側の＋1を含む）に特化します。
柔軟性などの残基尺度から、実際の剛直性・露出度・切断効率は断定しません。
[使い方・TSignalの設定・注釈形式](docs/explorer.md)を参照してください。

![一配列の探索画面。人工配列と手動の切断注釈を使用](docs/media/explorer-desktop.png)

以下は従来のPython API・CLIによる高度な解析です。

シグナルペプチドは、タンパク質の輸送に関わる短い配列です。本ライブラリは、
研究者が選んだ配列の疎水性、組成、電荷の簡易指標などを計算し、
変異による変化と、領域注釈による違いを調べるための道具です。

| 調べたいこと | できること |
|---|---|
| 領域の区切り方で説明が変わるか | 複数の注釈で特徴量の最小値・最大値・幅を計算 |
| どの位置の変異が何を変えるか | 一残基置換を列挙し、各注釈で元配列との差を計算 |
| 注釈を変えても変化の方向が同じか | 全注釈で増加・減少・不変か、注釈に依存するかを区別 |
| 配列のどこが数値に寄与しているか | 各残基の尺度値と、N/H/C領域への所属を表示 |
| アミノ酸組成だけで説明できるか | 組成を保った並べ替え配列と比較し、順序依存性を調べる |
| 二つの変異は特徴量の上で足し算になるか | 二重変異の変化と、単独変異の変化の和を比較 |

N/H/Cは、N末端側・中央・C末端側を指す領域名です。
研究で使う領域境界とその出典は、利用者が指定します。

配列 `MKALLLSAAA` の3番目のAをLに変える例では、Hを `ALLL` と区切ると
Hの平均疎水性は0.5増えます。Hを `LLL` と区切ると、そのAはHの外になるため、
Hの平均疎水性は変わりません。配列全体の平均疎水性は、どちらでも0.2増えます。
これは計算を確認するための人工配列であり、分泌実験の結果ではありません。

## インストールして試す

Python 3.12以上を使います。

```bash
git clone https://github.com/yktsnd/signal-peptide-features.git
cd signal-peptide-features
python -m pip install -e .
python examples/research_walkthrough.py --output-dir research-output
```

特徴量、領域感度、一残基変異、残基ごとの数値、並べ替え対照、二重変異の六つの表が
出力されます。計算は手元で完結します。APIキーやGPUは要りません。

自分の配列では、次の形で使います。

```bash
sp-features your_sequences.fasta --regions your_regions.csv --mutation-scan -o mutations.csv
```

領域CSVの列は `sequence_id,annotation_id,n_end,h_end,source` です。
FASTAの配列IDと一致させ、境界の出典も記録します。座標は0から数え、終端を含みません。
変異の位置は1から数えます。詳しい形式と全コマンドは[英語版README](README.md)にあります。

各結果には、配列、領域境界、出典、ソフトウェアの版、SHA-256値が残ります。
SHA-256は、配列や実装を識別するための値です。再計算で同じものを使ったか確認できます。
[計算方法](docs/methods.md)、[検証範囲](docs/validation.md)、
[ここから調べられる研究の問い](docs/research-questions.md)を合わせて参照してください。

論文の方法欄には、版・コミット、特徴量と原典、配列の出典と切断位置、
領域の決定方法を記します。分泌量を予測する性能や、生物学的な変異間相互作用は
未検証です。特徴量の変化と分泌性能の関係は、実測データで検証する必要があります。
