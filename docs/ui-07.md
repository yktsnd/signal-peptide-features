# UI 0.7: a single-sequence reading workflow

Start with an amino-acid sequence or open the synthetic example in one action. Known cleavage is optional and visible, with a position preview. The input distinguishes a full precursor from an isolated SP and explains FASTA on request. Errors preserve inputs and offer retry.

The result starts with a factual scope statement and annotation basis. The initial known-cleavage view covers the SP from position 1 through the adjacent mature residues. The full-input overview provides orientation; SP/mature and N/H/C bands, the residue strip and property plots share horizontal coordinates. Narrow screens zoom to a readable residue interval, avoiding misleading wrapped-row/plot alignment. Plot values update with selection; definitions and sources remain available beside the inspector. Range means expand on demand. No efficiency ranking or unsupported high/low interpretation is added.

SVG and HTML outputs include the region map and provenance alongside property tracks. Full metrics, physiological × physicochemical index, external structure annotations, session restoration, peptides distinction and advanced comparisons remain available. Content-free opt-in usage is versioned 0.7.

Validation includes coordinate/export model tests, 15 rendered states, native Python tests, usage contract tests, and CI browser interactions. CI saves synthetic desktop/mobile screenshots for visual inspection. Researcher task-observation remains separate; automated checks do not demonstrate comprehension.

Public TSignal: no TSIGNAL_URL is configured. The packaged CPU inference service exists but requires a separately hosted long-running Python/PyTorch service; the current Sites Worker runtime cannot hold the approximately 2 GiB checkpoint. No external container hosting account or endpoint is connected in this session. The public status now checks model health, distinguishes unavailable from unconfigured, and the UI supports retry. Public automatic prediction is not claimed as operational.
